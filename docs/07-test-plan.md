# 测试计划（Test Plan）

## 1. 文档目标
本文档定义本项目在 MVP 阶段的测试范围、测试策略、测试分层和验收方式，确保系统具备：
- 可运行性
- 可验证性
- 可回归性
- 可交付性

## 2. 测试范围
### 2.1 后端测试
- 地理编码适配器
- 天气适配器
- 空气质量适配器
- 风险评分服务
- 异常检测服务
- 工作流执行器
- 统一错误处理

### 2.2 前端测试
- 城市选择与参数提交
- 指标卡片展示
- 趋势图容器渲染
- 风险面板与异常面板渲染
- 加载态、空态、错误态

### 2.3 联调测试
- 前端请求后端
- 后端调用外部接口
- 后端返回展示模型
- 前端正确消费展示模型

## 3. 测试分层
### 3.1 单元测试
目标：验证单个函数、服务或组件的输入输出是否符合预期。

建议覆盖：
- 风险评分规则
- 异常检测规则
- 外部响应标准化逻辑
- Vue 组件 props 映射逻辑

### 3.2 集成测试
目标：验证多个模块组合后的行为是否正确。

建议覆盖：
- 工作流执行器 + 适配器
- 工作流执行器 + 分析服务
- 后端统一接口 + 数据契约

### 3.3 界面测试
目标：验证前端页面在关键状态下是否正确展示。

建议覆盖：
- 默认城市查询
- 城市切换后重新加载
- 风险等级变化时的颜色和文案变化
- 异常提示模块显示 / 隐藏逻辑

### 3.4 手工验收测试
目标：从业务视角验证系统是否满足题目要求。

## 4. 关键测试场景
### 4.1 正常场景
- 输入有效城市名，可成功加载天气与 AQI 数据
- 风险评分服务返回成功结果
- 异常检测服务返回正常或无异常结果
- 页面可正确展示卡片、图表和风险结果

### 4.2 异常场景
- 地理编码无匹配结果
- 天气接口超时
- 空气质量接口超时
- 外部接口返回字段缺失
- 风险评分接口异常
- 异常检测接口异常
- 前端收到部分降级结果

### 4.3 边界场景
- 仅提供坐标，不提供城市名
- AQI 极低或极高
- 小时级时间序列为空
- 风险阈值配置非法
- 工作流关闭异常检测开关

## 5. 必测异常清单
| 异常类型 | 预期行为 |
|---|---|
| 网络失败 | 返回统一错误对象或降级结果 |
| 请求超时 | 触发超时处理，并显示友好提示 |
| 空数据 | 页面显示空态，不直接崩溃 |
| 错误格式 | 后端拒绝非法数据并记录日志 |
| 算法不可用 | 原始数据可展示，分析模块提示不可用 |

## 6. 测试工具建议
- 后端：pytest
- 前端：Vitest
- 接口调试：HTTP 客户端 / Swagger / Postman 类工具
- Mock：本地 JSON 样本 / 假数据服务

## 7. 测试数据策略
- 使用固定城市作为基础样例：北京、上海、广州
- 使用本地样本覆盖正常 / 异常 / 边界情况
- 对高风险、低风险、异常突变分别准备独立样例

## 8. 验收清单
- 城市选择可以驱动完整流程
- 至少一个天气接口可用
- 至少一个空气质量接口可用
- 至少一个算法接口可用
- 前端正确展示趋势图和风险结果
- 错误态、空态、加载态可验证
- 工作流配置文件可被解释执行
- AI Skills 记录和代码审查报告已补齐
