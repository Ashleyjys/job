# api-wrapper-generator

## 用途
用于辅助生成或审查外部 API 与内部算法接口的封装层代码，重点覆盖：
- 请求参数映射
- 响应字段标准化
- 超时与重试
- 错误处理
- 数据契约一致性

## 适用场景
- 生成天气接口适配器
- 生成空气质量接口适配器
- 生成地理编码接口封装
- 生成风险评分 / 异常检测接口调用封装

## 建议输入
- 接口 URL
- 请求参数
- 返回字段
- 超时与重试要求
- Mock / Fallback 策略

## 期望输出
- adapter / service 层代码草稿
- 输入输出模型定义建议
- 错误处理分支建议
- 单元测试关注点

## 本项目中的主要用途
- 统一封装 Open-Meteo 系列接口
- 统一封装 `/api/v1/analysis/*` 内部算法接口
