# code-reviewer

## 用途
用于辅助执行本项目的代码审查，重点关注：
- 分层是否清晰
- 数据契约是否一致
- 错误处理是否完整
- 是否存在硬编码
- 测试覆盖是否足够

## 适用场景
- 后端 adapter / service / router 审查
- 工作流执行器审查
- Vue 页面与组件审查
- 风险评分与异常检测逻辑审查

## 审查维度
- 架构合理性
- 可维护性
- 可测试性
- 风险点识别
- 与文档一致性

## 建议输出格式
- 问题编号
- 影响模块
- 问题描述
- 风险等级（P1 / P2 / P3）
- 修改建议
- 是否必须修复

## 本项目中的主要用途
- 形成 `docs/09-code-review-report.md` 的实际问题记录
- 作为 AI 模拟 review 的输入模板
